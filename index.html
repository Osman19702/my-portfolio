PromptFixer

lint · score · rewrite

Lint, score and rewrite LLM prompts. A Windows desktop app with a built-in local model; cloud providers optional.

I built it with Claude Code, for personal use: fixing a prompt before I send it means fewer wasted tokens and a better first answer.

  • Scores a prompt instantly against ~30 prompt-engineering rules.
  • Rewrites it with a local model (Qwen3-4B via node-llama-cpp). Runs offline; nothing you type leaves the machine.
  • Re-scores the rewrite and shows a word-level diff with a change log for every edit.

Elastishot

align · diff · name the locator

Visual comparison for web UIs. It lines two screenshots up before it diffs them, so a banner or a collapsed section is one change instead of a page of red, and it names the DOM element behind every region.

I built it with Claude Code after one pixel-diff run too many that flagged everything. This site now runs it before every release (npm run visual, every section, both themes, two widths).

  • Feature alignment (ORB + RANSAC) recovers zoom, crop and shift; a strip alignment absorbs sections that grew, collapsed or moved.
  • Regions are added, removed, changed or moved, each attributed to a test id, role or CSS path from an element map recorded at capture time.
  • HTML report with a slider, flip, blink, overlay and diff viewer, plus JSON, JUnit and exit codes for CI. Open source, MIT, no telemetry.
TypeScriptNode.jsopencv.js (WASM)PlaywrightWeb Componentsnode:test

ATDD: 29 Gherkin scenarios driving the built CLI, plus 132 unit, engine and browser tests.
